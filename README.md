One line, under 160 characters: the funniest out-of-office reply — an away message that still reads like a real one, with a fresh joke instead of the usual beach-and-inbox cliché.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line to `/output/entry.txt`, where the make.fun judge reads it. Stdlib only, deterministic, no network, no input, no randomness.

## The line

> Out of office until Monday — my inbox is in the care of the office goldfish, who has already requested a transfer to a quieter bowl.
